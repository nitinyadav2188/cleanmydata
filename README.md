# CleanMyData (CMD) 🚀

![CleanMyData Hero Section](images\image0001.png)
![CleanMyData Tools Section](images\image0002.png)

CleanMyData is a professional, browser-based platform designed for data scientists, analysts, and ML students. It provides a comprehensive suite of tools to clean, visualize, engineer features, and train machine learning models directly in your browser—100% free and secure.

![CleanMyData](https://img.shields.io/badge/Status-Active-success) ![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=flat&logo=typescript&logoColor=white) ![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB) ![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=flat&logo=tailwind-css&logoColor=white)

## ✨ Features

*   🧹 **Data Workspace & Cleaning**: Instantly handle missing values, remove duplicates, format text, and detect outliers.
*   📊 **Powerful Visualizations**: Generate instant Exploratory Data Analysis (EDA) reports and visualize distributions effortlessly using interactive charts.
*   🧠 **ML Model Training**: Train machine learning models (Random Forest, Logistic Regression, Decision Trees, Gradient Boosting) directly in the browser. Features a live training console, feature importance charts, and loss curve visualizations.
*   🔄 **Free File Converters**: Fast, secure, and free online file converters. Seamlessly switch between CSV, JSON, and Excel formats.
*   🤖 **AI Data Assistant**: Chat with an AI-powered assistant (integrated with Google Gemini) to get insights, ask questions about your dataset, and receive data science guidance.

## 🛠️ Tech Stack

*   **Frontend Framework**: React 18 with TypeScript
*   **Build Tool**: Vite
*   **Styling**: Tailwind CSS
*   **Icons**: Lucide React
*   **Animations**: Framer Motion
*   **Charts**: Recharts
*   **Data Processing**: PapaParse (CSV), XLSX (Excel)
*   **AI Integration**: Google GenAI SDK (Gemini)

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nitinyadav2188/cleanmydata.git
   cd cleanmydata
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file in the root directory and add your Google Gemini API key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:3000` (or the port specified by Vite).

## 🔒 Privacy & Security

CleanMyData processes your data directly in your browser. Your datasets are not uploaded to any external servers for processing (except for queries explicitly sent to the AI assistant), ensuring your sensitive data remains secure and private.
